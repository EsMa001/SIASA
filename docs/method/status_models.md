# Statusmodelle

Regelbasierte Statusdefinitionen fuer Domänen und Multi-Domain-Status. Quelle: `stakeholder_requirements_information_space_mvp_v0_4 (1).xlsx` / Sheet `Status_Models`.

| Modell | Status | Name | Definition |
| --- | --- | --- | --- |
| Domänenstatus | D0 | nicht bewertbar | Datenlage reicht nicht aus; keine belastbare Aussage möglich. |
| Domänenstatus | D1 | unauffällig | Signal liegt innerhalb erwartbarer Baseline. |
| Domänenstatus | D2 | leicht auffällig | Geringe Abweichung von Baseline; beobachten. |
| Domänenstatus | D3 | deutlich auffällig | Robuste Abweichung von Baseline; relevante Domänendynamik. |
| Domänenstatus | D4 | stark auffällig | Sehr starke, belastbare Abweichung; hohe Aufmerksamkeit erforderlich. |
| Domänenstatus | D5 | widersprüchlich / mehrdeutig | Signale innerhalb der Domäne widersprechen sich oder Interpretation ist unsicher. |
| Multi-Domain-Status | S0 | No relevant anomaly | Keine relevante Auffälligkeit in aktiven Domänen. |
| Multi-Domain-Status | S1 | Single-domain anomaly | Eine Domäne auffällig. |
| Multi-Domain-Status | S2 | Strong single-domain anomaly | Eine Domäne sehr stark auffällig. |
| Multi-Domain-Status | S3 | Multi-domain alignment | Mehrere Domänen gleichzeitig auffällig. |
| Multi-Domain-Status | S4 | High-confidence multi-domain anomaly | Mehrere Domänen deutlich/stark auffällig und gute Datenlage/Confidence. |
| Multi-Domain-Status | S5 | Contradictory / ambiguous pattern | Domänen widersprechen sich oder Muster ist mehrdeutig. |
| Multi-Domain-Status | S6 | Data insufficient | Datenlage reicht für belastbare Bewertung nicht aus. |
