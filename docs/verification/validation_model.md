# Validierungsmodell

Importiertes Validierungsmodell fuer Referenzfaelle. Quelle: `stakeholder_requirements_information_space_mvp_v0_4 (1).xlsx` / Sheet `Validation_Model`.

| Feld | Beschreibung |
| --- | --- |
| case_id | Stabile ID eines historischen Referenzfalls, z. B. VAL-UKR-2022-001. |
| country_id | Betroffenes Land / ISO-Code. |
| case_name | Sprechender Titel des Referenzfalls. |
| case_type | Klassifikation, z. B. military_escalation, protest_wave, cyber_outage, economic_shock. |
| time_start / time_end | Validierungszeitraum. |
| expected_domains | Erwartete relevante Domänen A–E. |
| expected_signal_pattern | Erwartetes Muster als qualitative Beschreibung, nicht als harte Zielwerte. |
| reference_sources | Externe Referenzen / Dokumentation. |
| validation_goal | Was geprüft werden soll. |
| known_limitations | Methodische Einschränkungen. |
| validation_metrics | Detection Lead/Lag, Domain Coverage, Domain Match, Status Match, FP/FN, Explainability, Data Sufficiency. |
